# Design and Analysis of an Energy-Efficient Processor and Hierarchical Memory System

## Course
CSA1203 – Computer Architecture

## Project Description
This project designs and analyzes an energy-efficient processor and hierarchical memory system for an industrial monitoring application.

## Main Areas
- Processor functional units
- Instruction execution cycle
- Addressing modes
- CPI and execution time
- Pipelined processor design
- Pipeline hazard analysis
- Superscalar processing
- Out-of-order execution
- Speculative execution
- SMT
- L1, L2 and L3 cache
- Virtual memory and paging
- SRAM, DRAM, NAND Flash, MRAM and RRAM
- Performance and energy analysis
- Engineering recommendation
- SDG 7, SDG 9 and SDG 12

## Repository Contents
The repository contains the architecture, calculations, analysis, results, simulations and final report.
